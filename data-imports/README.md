# data-imports

대시보드에 수동으로 반영하는 원본 데이터를 두는 폴더입니다.

## 경제 캘린더 업데이트

1. 캘린더 엑셀(인베스팅닷컴 등에서 내보낸 파일)을 이 폴더에
   **`calendar.xlsx`** 라는 이름으로 저장합니다. (기존 파일은 덮어쓰면 됩니다)

   엑셀 1행은 헤더여야 하고, 컬럼 순서는 다음과 같습니다:

   | 날짜 | 시간 | 통화 | 국가 | 발표월 | 표시 | 중요도 | 실제값 | 예상값 | Forecast | 이전값 |

   - 날짜: `2026/08/12` 또는 `2026-08-12`
   - 시간: 한국시간(KST) 기준 `HH:MM`
   - 중요도: `3`(=상) / `2`(=중) / `1`(=하)

2. 스크립트 실행:

   ```bash
   python3 scripts/update-calendar.py          # data.js 갱신
   python3 scripts/update-calendar.py --dry     # 미리보기(파일 안 씀)
   ```

3. 결과 확인 후 커밋·푸시(=배포):

   ```bash
   git add data.js && git commit -m "경제 캘린더 업데이트" && git push
   ```

### 스크립트가 자동으로 해주는 것
- 엑셀에 담긴 **날짜 구간만** 교체합니다. 그 밖의 기존 일정은 보존.
- 중요도 3→상 / 2→중 / 1→하 변환, 국가명 정규화(대한민국→한국, 유로 지역→유럽 등).
- **지표 사전과 연결된 발표**(미국 CPI·고용·ISM, 한국 CPI, 중국 무역수지 등)와
  같은 날·같은 국가·같은 개념이면 중복이므로 엑셀 쪽 행을 자동 제외합니다.
- `cal_` 번호를 1부터 다시 매깁니다.

> 새로운 지표를 지표 사전에 추가해 중복 제외 대상을 늘리고 싶으면
> `scripts/update-calendar.py` 의 `CONCEPT` 딕셔너리에 `지표id: (["포함키워드"], ["제외키워드"])` 를 추가하세요.

## 블룸버그 매크로 데이터 업데이트

1. 블룸버그 엑셀(고정 템플릿: `한국`/`미국`/`유중일호` + `_Daily 금융지표` + `스프레드`
   시트, 각 열에 `티커` 행이 있는 형식)을 이 폴더에 **`bloomberg.xlsx`** 로 저장합니다.

2. 실행:

   ```bash
   python3 scripts/update-bloomberg.py          # bloomberg-data.js 갱신
   python3 scripts/update-bloomberg.py --dry     # 미리보기(파일 안 씀)
   ```

3. 결과 확인 후 커밋·푸시(= 배포).

### 동작(안전 우선 — "최신값만 추가")
- 각 시리즈의 **티커로 엑셀 열을 찾아**, 현재 저장된 마지막 날짜보다 **더 최신인
  데이터만** 이어붙입니다. 과거값·라벨·단위는 절대 바꾸지 않습니다.
- 월별: `series`에 최신치 추가 + `releases`(최근 24개월) 롤포워드 + `nextRelease`/`survey_latest` 갱신.
- 일별(금융): 주간(일요일) 다운샘플로 신규 구간만 추가 + `asOf` 갱신.
- 엑셀에서 티커를 못 찾은 시리즈는 **건드리지 않고 보고**만 합니다.
- 엑셀에만 있는 **새 지표는 자동 생성하지 않습니다**(필요 시 수동 추가).

## 일별 금리·환율 (info_daily) 업데이트

1. 인포맥스류 일별 엑셀(시트 `DailyRate`, `Notation` 행에 KTB10y·UST0y·GER10y 등
   코드가 있는 형식)을 이 폴더에 **`info_daily.xlsx`** 로 저장합니다.

2. 실행:

   ```bash
   python3 scripts/update-rates.py          # rate-data.js 갱신 + 교차검증
   python3 scripts/update-rates.py --dry     # 미리보기(파일 안 씀)
   ```

3. 결과 확인 후 커밋·푸시(= 배포).

### 동작
- `rateData.dates` 의 마지막 날짜보다 **더 최신 영업일만** 이어붙입니다(과거값 보존).
- 각 시리즈를 `notation`(중복 시 등장 순서)으로 엑셀 열과 매칭.
- 홈 국채 카드(한·미·일·독·호 10Y)는 이 `rate-data.js`(일별·전 국가 일관)를 주 소스로 씁니다.

### 교차검증 (겹치는 데이터 상호 검증)
- 실행 시 `rate-data ↔ bloomberg` 의 겹치는 지표(각국 10Y, 원/달러, DXY)를 최근
  공통시점에서 비교해 ✅/⚠️ 로 보고합니다. 차이가 크면(⚠️) 어느 소스가 이상한지
  확인하세요. (예: info_daily의 원/달러 열이 특정 값에 고정돼 있으면 블룸버그 값이 정상)
